# RecruitGPT Academy

Free, structured US Staffing education. Static HTML/CSS/JS &mdash; no backend, no database, no login.

## Structure

```
index.html
terminology.html
us-culture-geography.html
eeoc.html
sourcing-booleans.html
employment-tax.html
work-authorization.html
call-flow-objections.html
email-phone-etiquette.html
css/style.css
js/interactive.js
```

## Run locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Deploy

Static site &mdash; deploys as-is on GitHub Pages or Vercel's free tier with zero configuration.
